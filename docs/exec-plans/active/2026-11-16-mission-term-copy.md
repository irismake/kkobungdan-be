# 사용자 표시 용어 통일 (행님·꼬붕·임무)과 임무 완료 알림 문구 변경

## 배경

화면에 보이는 한국어 용어가 섞여 있다. 같은 Mission을 `미션`과 `임무`로 부르고, 임무 완료 동작은 `만남 확인`이라고 부른다. 앱의 완료 버튼은 이미 `임무 수행 완료`다.
이번 작업에서 코드 용어(영문)와 사용자 표시 용어(한국어)를 아래와 같이 정하고, 서버가 만드는 문구를 이 표에 맞춘다.

| 코드 용어 | 사용자 표시 용어 |
|---|---|
| Proposal | 요청 (홈에 공개되어 지원할 수 있는 요청은 `게시물`·`게시글`) |
| Offer | 지원 |
| Orderer | 행님 |
| Runner | 꼬붕 |
| Mission | 임무 |
| complete_delivery | 꼬붕 임무 완료 (앱 버튼 `임무 수행 완료`) |
| confirm_received | 행님 임무 완료 확인 (앱 버튼 `임무 수행 완료`) |

## 결정 사항

| 항목 | 결정 |
|---|---|
| 용어 범위 | 사람이 읽는 한국어 문구는 모두 `임무`로 바꾼다. 앱 푸시, 관리자 웹 응답·오류 문구, Slack 운영 알림, API 설명이 대상이다. 코드 이름(Mission, mission_id 등)은 바꾸지 않는다 |
| 꼬붕 쪽 완료 | `꼬붕이 임무를 완료했어요` |
| 행님 쪽 완료 | 행님은 임무를 수행하지 않고 완료를 확인하므로 `행님이 임무 완료를 확인했어요` |
| 양측 완료 알림 본문 | 행님·꼬붕 모두 같은 본문을 쓴다 |
| `게시물`·`게시글` | 공개 요청을 가리키는 말이라 그대로 둔다 |
| 역할 호칭 | `오더러`·`오더`·`러너`·`요청자`·`지원자`·`수행자`·`고객`을 모두 `행님`·`꼬붕`으로 바꾼다. 코드 문자열, API 설명, 주석·docstring, 현재 문서가 대상이다. 브랜드명 `오더런`과 완료된 실행 계획(`docs/exec-plans/completed/`)은 바꾸지 않는다 |
| Offer 표기 | `오퍼`·`제안`(Offer를 뜻할 때)을 `지원`으로 바꾼다 |
| Chat | `채팅`. 채팅방은 `채팅방` |

## 문구 변경 내역

| 이벤트 | 받는 사람 | 변경 후 제목 | 변경 후 본문 |
|---|---|---|---|
| 꼬붕 선택 & 임무 시작 | 행님 | 임무가 시작됐어요! 🏃 | 꼬붕을 선택하셨어요! 임무를 바로 시작해보세요. |
| 꼬붕 임무 완료 | 행님 | 꼬붕이 임무를 완료했어요! 🤝 | 꼬붕이 임무를 완료했어요. 회원님도 확인해주시면 수행비가 꼬붕에게 전달돼요. |
| 행님 임무 완료 확인 | 꼬붕 | 행님이 임무 완료를 확인했어요! 🤝 | 행님이 임무 완료를 확인했어요. 회원님도 앱에서 임무 완료를 눌러주시면 정산이 바로 진행돼요! |
| 양측 임무 완료 | 행님·꼬붕 | 임무 수행 완료! 수고하셨어요 🎊 | 양측 모두 임무 완료를 확인했어요. 성공적으로 임무 수행이 완료됐습니다! |
| (미구현) 한쪽 미확인 리마인드 1차 | 미확인자 | 아직 임무 완료가 확인되지 않았어요 👋 | 상대방은 이미 임무 완료를 확인했어요. 앱에서 '임무 수행 완료' 버튼을 눌러주시면 정산이 바로 진행돼요! |
| (미구현) 한쪽 미확인 리마인드 2차 | 미확인자 | 임무 완료 확인을 기다리고 있어요 ⏳ | 아직 임무 완료 확인이 끝나지 않았어요. 확인이 어려우시면 고객센터로 문의해주세요. |
| Slack 임무 완료 | 관리자 | 💰 임무가 완료됐어요 — 수행비 입금이 필요합니다 | `임무 #{id} · 요청 #{id} «제목»` |

관리자 오류·응답 문구:

| 코드 | 변경 후 |
|---|---|
| 임무 없음 | 임무를 찾을 수 없습니다. |
| 분쟁 아닌 임무 판정 | 분쟁 중인 임무만 판정할 수 있습니다. |
| 지급 불가 상태 | 수행비를 지급할 수 없는 임무 상태입니다. |
| 분쟁 판정 성공 응답 | 임무 분쟁이 해결되었습니다. |

## 범위 밖

- 코드 주석·docstring과 설계 문서 본문의 `미션` 표기 (역할 호칭은 이번에 함께 바꿨다). 사람에게 보이는 문구가 아니므로 이번에는 두고, 필요하면 따로 정리한다.
- 앱 버튼 문구. 앱에는 이미 `임무 수행 완료`로 되어 있다.
- 채팅 시스템 채팅 문구는 `feature/chat` 브랜치의 `chat-requirements.md`에서 같은 용어로 정했다.
