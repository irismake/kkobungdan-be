# 알림 문구 개정 (행님/꼬붕 브랜드 보이스 반영)

## 배경

기획에서 푸시 알림 문구를 개정했다. 핵심 변경은 사용자 노출 문구의 호칭을
"요청자/지원자" → "행님/꼬붕"으로 바꾸고, "웨이팅" 표현을 "미션/수행비"로 정리한 것이다.
`docs/product-specs/notification-policy.md`의 스펙 표가 정본이며, 이 계획은 그 개정판을
서버 구현과 관련 문서에 반영한다.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 입금 취소(24시간) 타이틀/내용 | 새 스펙 표 배치를 그대로 적용한다. 타이틀에 `${요청제목}` 문장, 내용에 안내 문장. |
| 꼬붕 표기 | `꼬붕`으로 전체 통일한다. 기존 탈퇴 사유 문구의 `꼬봉`도 함께 교정한다. |
| 지원 수락 문구의 채팅방 입장 코드 | 채팅방 기능 미구현이므로 이번에도 제외하고 `문구 불일치` 항목으로 유지한다. |

## 후속

- 꼬붕 선택됨 알림의 "카카오톡 채팅방 입장 코드" 문구는 채팅방 연동 시 반영한다. 그때까지 정책 문서의 `문구 불일치` 항목으로 남는다.
- 랜딩 페이지 전달 필드(`navigation_code` 등) 부재는 그대로다. 스펙의 랜딩 페이지 열을 실제로 적용하려면 payload 확장이 선행돼야 한다.
