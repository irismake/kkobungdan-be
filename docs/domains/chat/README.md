# Chat Domain

> 상태: 초안 (뼈대만 작성됨)

ChatRoom(채팅방)은 지원(Offer) 1건마다 만들어지는 행님과 꼬붕의 1:1 대화 공간이다. 채팅방에는 참여자가 보낸 일반 채팅과 서버가 요청·지원·임무 사건에 맞춰 남기는 시스템 채팅이 저장 순서대로 쌓인다.
